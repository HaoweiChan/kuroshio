TradingAgents for your whole portfolio.

Kuroshio is an open-source quantamental portfolio engine: multi-factor screening, LLM agent research that is cheap enough to run daily, and rebalancing proposals governed by your own written investment policy. It ranks, argues, and proposes — it never places an order.

Apache-2.0 Python 3.11 – 3.13 ruff + pytest in CI zero API keys to start US & TW markets 
# zero-key path: yfinance data, pure-quant scoring
pip install "kuroshio[yfinance]"

1. Screen

Stage-1 breakout gates, then cross-sectional percentile scoring across momentum, volume, relative strength and market-specific factors. Pure functions — no network, no DB.

2. Research

A componentized TradingAgents pipeline runs analyst debate per holding. Facets are TTL-cached, so a daily run over a whole portfolio costs cents rather than dollars.

3. Propose

Your IPS — a markdown file with caps, hurdles and friction — decides. The allocator emits SWAP / TRIM / ALERT cards, each citing the exact clause that triggered it.

Validation · kuroshio backtest

Walk-forward, not curve-fit

Weekly rebalances over the trailing year, 20-day forward returns, top-5 basket, scored only on data available at each rebalance date.

Architecture

Pure compute, thin IO

Core logic never imports a data vendor. Providers are plugins, screening and allocation are pure functions over plain dataclasses, and every edge (CLI, Discord) is an adapter at the boundary.

Kuroshio — Apache 2.0. Includes components derived from TradingAgents (Apache 2.0); see NOTICE. Source: github.com/HaoweiChan/kuroshio.
